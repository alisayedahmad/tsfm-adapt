# tsfm-adapt

Adaptation de modèles de prévision de séries temporelles (TSFM) sur des données énergétiques,
via un petit adapter plutôt qu'un fine-tuning complet.

Travail en cours.

## Setup

```bash
python -m venv venv
source venv/bin/activate
pip install -r requirements.txt
```

## Structure

```
src/        code
data/       données (non versionnées)
notebooks/  exploration
```
